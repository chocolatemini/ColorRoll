# ColorBump

落ちてくるボールを、跳ねる線を描いて同じ色の箱へ入れよう！

iPad向けの、シンプルなのに難しい仕分けアクションゲームです。2026年の学祭の展示用に作りました。

## どんなゲーム？

- 画面の上を動く投入口から、色のついたボールが次々と落ちてきます。
- 指（またはApple Pencil）で線を描くと、当たったボールが跳ねて向きが変わります。
- ボールを、同じ色の箱に入れましょう。違う色の箱に入ったり、画面の外に出たりするとミスです。
- 描いた線は3秒で消えます。インクには限りがありますが、線が消えると戻ってきます。
- 画面上のレバーで、ボールが落ちる速さを「ゆっくり」「ふつう」「はやい」に切り替えられます。
- 色が見分けにくい人も遊べるように、ボールと箱には色ごとの印（赤○ 青△ 黄□ 緑✕）が付いています。

## モード

| モード | 内容 |
|---|---|
| あそぶ（サバイバル） | ライフがなくなるまで続けるモード。レベルが上がるごとに色やボールの数が増え、ななめに出るボールや跳ねる壁などの仕掛けも登場します。♥マークのボールを正しく入れるとライフが増えます。 |
| あそびかた | 4つのお題で、遊び方を順番に覚えられます。 |
| ステージ | 決まった数のボールを仕分ける、全8ステージ。結果は★で表示されます。 |
| ランキング | サバイバルの上位30人を、到達レベルとあわせて表示します。 |

タイトル画面で2分間だれも触らないと、デモプレイが流れます。

## 動かし方

### 必要なもの

- Xcode が入った Mac
- iPad（実機。ボールの動きや操作は実機で確かめるのがおすすめです）
- Apple ID（無料のものでOK）

### 手順

1. **プロジェクトを作る**
   Xcode で「File」→「New」→「Project」→「iOS」→「App」を選びます。Interface は「SwiftUI」、Language は「Swift」にします。

2. **ファイルを入れる**
   このリポジトリの次のファイルを、プロジェクトのフォルダに入れます。
   - `ContentView.swift`（もとからあるものと置き換え）
   - `GameScene.swift`
   - `Screens.swift`
   - `MyApp.swift`

   プロジェクトを作ったときにできた「〇〇App.swift」は削除してください。`MyApp.swift` と役割が同じなので、両方あるとエラーになります。

3. **画面の向きを横にする**
   プロジェクトの設定の「General」→「iPad Orientation」で、「Landscape Left」と「Landscape Right」だけにチェックを入れます。

4. **署名の設定**
   「Signing & Capabilities」の「Team」で、自分の Apple ID の「Personal Team」を選びます。Bundle Identifier は、ほかと重ならない名前にしてください。

5. **iPadで動かす**
   iPad を Mac につなぎ、iPad の「設定」→「プライバシーとセキュリティ」→「デベロッパモード」をオンにします。Xcode で iPad を選んで ▶ を押すと動きます。
   初回に開けないときは、iPad の「設定」→「一般」→「VPNとデバイス管理」で、自分の Apple ID を信頼してください。

無料の Apple ID で入れたアプリは、7日ほどで起動できなくなります。そのときは Xcode からもう一度 ▶ で入れ直してください。データは消えません。

## 調整のしかた

ゲームの数値は、ほとんどが `Screens.swift` にまとまっています。

| 調整したいもの | 場所 |
|---|---|
| サバイバルの難しさ（ノルマ・色の数・同時に出るボールの数・間隔・ハート・仕掛け） | `SurvivalRule.levels`（1行が1レベル） |
| ステージの中身 | `Stages.all` |
| デモプレイ（始まるまでの時間・長さ・説明文） | `DemoSettings` |
| ランキングに出す学祭の日程 | `FestivalDays` |
| ランキングに残す人数 | `SaveData.rankingSize` |

線の長さや跳ね返りの強さなど、プレイ中の手触りは `GameScene.swift` の上のほうで調整できます。

## 開発者メニュー

タイトルの文字を5秒長押しして、パスコードを入れると開きます（パスコードは `Screens.swift` の `DevSettings.passcode`）。

- 無敵モード、サバイバルの開始レベルの設定（このあいだのスコアはランキングに残りません）
- テスト記録の登録（ランキングには「0日目(テストプレイ)」と表示されます）
- ランキングの記録を選んで消す、全部リセットする

## 使っている技術

- Swift / SwiftUI
- SpriteKit（物理演算と描画）

ランキングは iPad の中（UserDefaults）にだけ保存されます。
